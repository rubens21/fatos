# Spec Delta

## Purpose

Oferece no rodapé um canal de contato por e-mail para quem quiser colaborar com o site Fatos e Evidências.

## ADDED Requirements

### Requirement: Rodapé com e-mail de colaboração
O sistema MUST exibir um rodapé com um link `mailto:` para o e-mail de contato de colaboração.

#### Scenario: Link mailto no rodapé
- **WHEN** o usuário visualiza a página do site (incluindo página de indivíduo carregada ou estado de não encontrado)
- **THEN** o rodapé MUST estar visível e MUST conter um link `mailto:` apontando para o e-mail de contato de colaboração
